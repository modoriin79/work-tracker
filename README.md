# Work Tracker

프로젝트 · 할 일 · 집중 시간을 한 곳에서 추적하는 개인 작업 트래커. 빌드 없이 GitHub Pages에서 바로 동작합니다.

## 기능
- **오늘**: 오늘 고정(☆)·진행 중·마감 지난 일을 자동으로 모아 보여줌, 7일 이내 마감, 오늘 끝낸 일, 하루 회고
- **빠른 추가 문법**: `발표 슬라이드 #신호 !1 ~11/10 @40` → 프로젝트 / 우선순위 / 마감일 / 예상 시간(분)
- **보드**: 할 일 · 진행 중 · 완료 칸반, 드래그로 상태 변경, 프로젝트별 필터
- **프로젝트**: D-day, 완료율, 누적 집중 시간, 2개월 타임라인
- **집중 타이머**: 25분 / 50분 / 스톱워치. 작업별로 시간이 자동 기록되고 새로고침해도 이어짐
- **기록**: 주간 집중 시간(요일별·프로젝트별), 완료 수, 연속 집중일, 세션 로그
- 단축키: `1`~`4` 화면 전환, `n` 할 일 추가, `Space` 타이머 시작/정지

## 데이터
- 기본: 브라우저 localStorage (기기별)
- 기기 간 동기화: 설정 → GitHub 토큰(gist 권한만) 입력 → 비공개 Gist에 저장
- 백업: 설정 → JSON 내보내기 / 가져오기

## 배포
`main` 브랜치에 push하면 GitHub Pages(Settings → Pages → Deploy from branch → `main` / root)로 자동 반영됩니다.
