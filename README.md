# Work Tracker

벌려놓은 프로젝트·공모전과 할 일을 한눈에 정리하는 개인 작업 트래커. 빌드 없이 GitHub Pages에서 바로 동작합니다.

## 기능
- **벌려놓은 일 (사이드바)**: 진행 중·시작 전·보류인 프로젝트/공모전/수업/인턴 등을 마감 가까운 순으로 항상 표시. 클릭하면 해당 항목으로 이동
- **벌린 일 탭**: 전체 목록 — 종류(공모전·프로젝트·수업·과제·인턴·연구·자격증·어학·대외활동·개인·기타), 상태(진행 중/시작 전/보류/끝남), D-day, 진행률, 다음 할 일, 한 줄 메모, 링크. 종류별 필터, 펼치면 할 일 목록·추가. 아래에 기간 타임라인
- **오늘**: 오늘 고정(☆)·진행 중·마감 지난 일을 자동으로 모아 보여줌, 7일 이내 마감, 오늘 끝낸 일, 하루 회고
- **빠른 추가 문법**: `발표 슬라이드 #신호 !1 ~11/10` → 벌린 일 / 우선순위 / 마감일 (`~오늘`, `~내일`도 가능)
- **보드**: 할 일 · 진행 중 · 완료 칸반, 드래그로 상태 변경, 벌린 일별 필터
- 단축키: `1`~`3` 화면 전환, `n` 할 일 추가, `p` 새로 벌린 일 추가

## 미니 위젯
- `?mini` 주소(https://modoriin79.github.io/work-tracker/?mini)로 열면 벌려놓은 일 + 오늘 할 일만 있는 작은 화면
- 사이드바의 **📌 작은 창으로 띄우기** → 다른 창 위에 항상 떠 있는 작은 창 (Edge/Chrome)
- `launcher/start-mini.ps1`: Edge 앱 창으로 미니 화면을 열어 화면 오른쪽 아래에 항상 위로 고정. Windows 시작프로그램/바탕화면 바로가기가 이 스크립트를 실행함
  - 시작 시 자동 실행을 끄려면 `Win+R` → `shell:startup` → `Work Tracker` 바로가기 삭제
- 여러 창·탭을 열어도 변경 사항이 즉시 서로 반영됨

## 데이터
- 기본: 브라우저 localStorage (기기별)
- 기기 간 동기화: 설정 → GitHub 토큰(gist 권한만) 입력 → 비공개 Gist에 저장
- 백업: 설정 → JSON 내보내기 / 가져오기

## 배포
`main` 브랜치에 push하면 GitHub Pages(Settings → Pages → Deploy from branch → `main` / root)로 자동 반영됩니다.
